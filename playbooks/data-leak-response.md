# Data Leak Response Playbook

## Detection

Identify unauthorized exposure of sensitive, confidential, regulated, proprietary, mission, or personal data.

## Containment

- Disable affected system access.
- Stop data export paths.
- Revoke exposed credentials if applicable.
- Preserve logs.

## Assessment

Determine data type, affected parties, exposure path, vendor involvement, legal duties, and notification requirements.

## Correction

- Patch access controls.
- Limit data categories.
- Update vendor contract controls.
- Add monitoring and alerts.
- Train users on data restrictions.

## Reauthorization Trigger

Reauthorize only after containment, legal review, and control testing.
