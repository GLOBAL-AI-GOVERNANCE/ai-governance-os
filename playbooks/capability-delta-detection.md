# Capability Delta Detection Playbook

## Purpose

Trigger review when an AI system gains meaningful new capability.

## Automatic Review Triggers

- New model version
- New tool access
- New autonomous workflow
- New external action permission
- New data category
- New user population
- New high-impact use case
- Serious incident
- Evidence of deception, goal-hacking, or unauthorized tool use
- Truth-verifiability degradation
- Major improvement in planning, coding, persuasion, cyber support, or scientific reasoning

## Capability Delta Levels

### Minor

Improved speed, formatting, or basic accuracy without new permissions.

### Material

Improved reasoning, tool use, coding ability, persuasion, cyber support, or domain capability.

### Major

New autonomy, long-horizon planning, self-directed tool use, high-impact decision support, strategic capability, or capability that may affect public safety, national security, or verifiable knowledge production.

## Required Action

Minor: document change.
Material: rerun risk assessment.
Major: reopen all frontier gates.

## Command Rule

Capability increase must trigger evidence increase.
