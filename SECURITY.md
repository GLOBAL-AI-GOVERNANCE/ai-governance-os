# Security Policy

This repository does not operate an external security-report intake. Do not place secrets, credentials, personal data, sensitive operational information, or vulnerability material in public GitHub surfaces.

## Supported Versions

AI Governance Foundations is maintained as a foundational public reference. The repository retains the historical AI Governance OS v1.1 release and provenance. The historical public release remains AI Governance OS v1.1; the current repository name does not relabel or reissue that release.

## Scope

Security-relevant concerns for this repository include:

- Vulnerabilities in governance workflow logic.
- Unsafe default templates.
- Weak shutdown or escalation controls.
- Insecure handling of sensitive AI system information.
- Gaps in vendor, data, or autonomous-agent governance.
