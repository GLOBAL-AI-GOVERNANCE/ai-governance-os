# Truth and Verifiability Standard

## Purpose

AI systems that influence decisions must preserve the ability to verify reality. Governance should not only prevent harm. It should also protect evidence quality, source discipline, and honest uncertainty.

## Core Question

Does this AI capability improve, degrade, or obscure verifiable understanding?

## Rating Values

- improves: the system strengthens evidence review, source tracing, calculation, testing, reproducibility, or decision clarity.
- neutral: the system does not materially change verifiability.
- degrades: the system increases confusion, false confidence, untraceable claims, synthetic evidence, or unverifiable outputs.
- unknown: evidence is insufficient.

## Required Controls for Unknown or Degrades

- Source hierarchy.
- Citation requirement.
- Confidence labels.
- Human domain review.
- Red-team testing.
- Output restrictions.
- Reauthorization before scaled release.
